# Alamdar Hussain — Portfolio

A responsive static portfolio and tailored resume for Solution Architect and Delivery Manager roles. It uses plain HTML and CSS and can be published through GitHub Pages without a build step.

## Preview locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Put `index.html`, `styles.css`, `Alamdar-Hussain-Solution-Architect-Delivery-Manager.pdf`, and `ITIL-Foundation-Version-5-Certificate.pdf` in the root of your GitHub repository.
2. Commit and push the changes.
3. In the repository, open **Settings → Pages**.
4. Choose **Deploy from a branch**, select your publishing branch and `/ (root)`, then save.

## Connect the Google inquiry form

The contact section has a styled placeholder ready for your form. To create it:

1. Go to [Google Forms](https://forms.google.com) and choose **Blank form**.
2. Title it **Solution Architecture & Delivery Inquiry**. Suggested fields: name, email, company (optional), inquiry type, and a short description of the need. Add timeline as an optional field.
3. Select **Publish** and set responder access to **Anyone with the link** if you want visitors outside your organization to submit.
